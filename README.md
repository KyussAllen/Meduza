# Meduza

## Overview

Meduza is a first-person survival horror game built in Unreal Engine 5.

After a violent storm strands a lone fisherman on an abandoned offshore oil rig, he discovers that something has already claimed the structure. As supplies dwindle and the rig slowly falls apart, the player must survive seven days while avoiding a mysterious creature capable of mimicking the life it consumes.
